# ML_HS26

Machine learning project, autumn semester 2026 (HS26).

## Repository structure

| Folder | Contents |
|---|---|
| `Scripts/` | Code: data cleaning, feature engineering, model training and evaluation |
| `Raw data/` | Original, unmodified source data (never edit these files) |
| `Analysis data/` | Cleaned and processed datasets produced by the scripts |
| `Reports/` | Figures, tables, write-ups and final reports |

## Workflow

1. Place source files in `Raw data/`.
2. Run the scripts in `Scripts/` to produce datasets in `Analysis data/`.
3. Save results and write-ups in `Reports/`.

## Getting started

```bash
git clone https://github.com/<your-username>/ML_HS26.git
cd ML_HS26
```
